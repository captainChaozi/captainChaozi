# chaozi

I build and test small web tools, automation workflows, and agent-native operating systems.

## Public Tools

- [Window Peeper AI](https://windowpeeperai.pro/) - turn one adult portrait into a 14-second 9:16 Window Peeper-style meme video (credit packs from about $6.90; free guides on the site).
- [CompressMP4](https://compressmp4.org/?utm_source=github-profile&utm_medium=profile&utm_campaign=promotion) - browser-local MP4 compression with percentage and target MB controls.
- [Compress video for Gmail](https://compressmp4.org/compress-video-for-gmail) - reduce video size for email attachment limits.
- [Discord video compressor](https://compressmp4.org/discord-video-compressor) - make smaller MP4 files for chat and community uploads.

## Games I build

- [PokéBonk Wiki (BonkDex)](https://pokebonk.info/) - my fan wiki for the free PokéBonk browser survivor game: play in the browser, a 151-entry Pokédex, guides, a tier list maker and a type chart. Unofficial fan project, not affiliated with Nintendo or the game's creator.
- [Daily Red](https://daily-red.app/) - a daily Pokémon team-building challenge against one fixed opponent.
- [Plain Game](https://plaingame.fun/) - a free daily estimation game: seven guesses to name something close to a target number or estimate a fact. Independent edition, not affiliated with the original Plain.
